# SVG Icons

Place all SVG icon files here.

Naming convention: `icon-name.svg` (kebab-case, lowercase)

Examples:
- `search.svg`
- `calendar.svg`
- `user-circle.svg`
- `heart.svg`

Usage in code:
```tsx
import Image from 'next/image';
<Image src="/assets/svg/search.svg" alt="Search" width={20} height={20} />
```
